# Locus Converter — JSON → GPX / KML

Локальное приложение (веб-интерфейс + локальный сервер), которое превращает
произвольный JSON с точками (POI) в файлы **GPX 1.1** или **KML 2.2** для
приложения **Locus Map** — с названиями, HTML-описаниями, форматированием,
ссылками и картинками, подгружаемыми в описания точек.

Написано на **TypeScript** (строгая типизация, без `any`). Фронтенд — **React +
Material UI + styled-components** (сборка Vite), сервер — Node.js. Работает
полностью локально; единственное внешнее соединение — бесплатный переводчик
Google.

---

## Запуск

Нужен только **Node.js** (v18+).

Windows — просто запустите:

```
run.bat
```

`run.bat` сам установит зависимости (`npm install`), соберёт проект и запустит
сервер. Либо вручную:

```
npm install
npm run build
node build/server.js
```

Затем откройте в браузере: **http://localhost:8123**

## Как пользоваться

1. **Загрузите JSON**: вставьте текст, выберите файл или положите `.json` в
   папку `data/input` и выберите его в интерфейсе.
2. **Изучите поля** — слева показываются все поля файла с типами, примерами
   и статистикой пустых значений. Координаты (`lat`/`lon`) определяются
   автоматически.
3. **Соберите шаблон** — название точки (`{{поле}}`) и блоки описания:
   `Поле`, `Картинка`, `Список`, `Ссылки`, `Текст`, `Разделитель`. У поля —
   обёртка (`обычный` / `заголовок` / `жирный` / `курсив`), переключатель
   разметки `</>`, подпись и флаг «переводить».
4. **Предпросмотр** справа показывает точку как на экране Locus Map
   (рамка ≈ Oppo Find X9 Pro); обновляется при изменении шаблона.
5. **Предперевод (отдельный шаг)** — кнопка «Перевести и сохранить JSON» в
   панели справа переводит только отмеченные поля (с учётом флагов
   «переводить») и сохраняет результат в `data/output/<имя>_<язык>.json`.
   После этого интерфейс переключается на переведённые данные (их видно в
   предпросмотре и в списке полей), а файл можно скачать по ссылке.
   Сохранённые переводы доступны во вкладке «Переводы» панели «Источник
   JSON» — нажмите файл, чтобы загрузить его и работать уже с ним.
6. **Конвертация** («▶ Конвертировать»): сначала переводятся отмеченные поля
   (пачками по 50 строк), результат сохраняется как копия исходного JSON с
   переведёнными полями (`data/output/<имя>_<язык>.json`), затем генерируется
   GPX/KML.
7. **Скачайте** файл и импортируйте в Locus Map (My Library → Import).

## Формат вывода

### GPX (рекомендуется)

- `<name>` — название точки;
- `<desc><![CDATA[ … ]]></desc>` — HTML-описание (`<b>`, `<i>`, `<br>`,
  `<a href>`, `<img src>`, `<ul>/<li>`, `<hr>`, `<font size>`);
- `<url>` / `<urlname>` — ссылка и её название (опционально);
- `<sym>` — иконка (опционально).

### KML

- `<Placemark><name>` и `<description>` (тот же HTML), координаты в `<Point>`.

### Ссылки точки (`<url>` / `<urlname>`)

- В GPX у каждой точки могут быть `<url>` и `<urlname>` — как в `result-example.gpx`.
- Откуда берётся ссылка (по порядку): поля **«URL (GPX url)»** / **«Название ссылки»**
  в разделе «Дополнительно», затем первый URL из блока **«Ссылки»**
  (массив `sources[{url, name}]`).
- Шаблон по умолчанию подставляет поля автоматически, если в JSON есть
  `url`, `link`, `website`, `atlas_url`, `source_url`, `permalink`
  (или вложенный путь вида `data.url`), а для названия — `urlname`, `url_name`,
  `link_name`, `title`.
- Если названия нет — используется название точки.
- В KML тегов `<url>` нет, поэтому ссылка добавляется в `<description>` —
  и только если её там ещё нет (блок «Ссылки» уже мог её вывести).

Картинки в описании (`<img src="http…">`) Locus подгружает при наличии сети;
`file://` работает для локальных файлов.

## Типы полей, которые красиво смотрятся в Locus

| Блок                    | Как выглядит                            | Замечание                        |
| ----------------------- | --------------------------------------- | -------------------------------- |
| **Заголовок**           | крупный жирный текст                    | `<font size="4"><b>…</b></font>` |
| **Абзац (с разметкой)** | текст, `**жирный**`, `*курсив*`, ссылки | универсальный                    |
| **Картинка**            | `<img>` по ширине                       | Locus грузит http/https          |
| **Список**              | маркированный `<ul><li>`                | для массивов строк               |
| **Ссылки**              | кликабельные `<a href>`                 | для массивов `{url, name}`       |
| **Разделитель**         | линия `<hr>`                            | отделяет блоки                   |
| **URL / urlname**       | поле «Веб-сайт» точки                   | GPX `<url>` + `<urlname>`        |

## Обёртка и разметка

Форматирование значения — это два независимых переключателя:

- **Обёртка** (выпадающий список у блока «Поле»): `обычный`, `заголовок`
  (`<font size="4"><b>…</b></font>`), `жирный` (`<b>…</b>`), `курсив`
  (`<i>…</i>`).
- **Разметка** (иконка `</>` рядом с полем): включена — текст проходит через
  Markdown-конвертер (`**жирный**`, `*курсив*`, `[текст](url)`, `<emo>🧭</emo>`,
  известные HTML-теги); выключена — текст выводится **как есть**, а `<`, `>`,
  `&` экранируются.

Разметку стоит отключать, если символы `*` и `_` в значении не являются
разметкой (например «5 _ 4 _ 3 м» превратится в «5 <i> 4 </i> 3 м», а
`on_site_radius_meters` — в `on<i>site</i>radius_meters`). Переносы строк
(`\n`) в обоих режимах становятся `<br>`, пустая строка — `<br><br>`.

У блока «Текст» такая же иконка `</>`; у элементов «Списка» свой мини-формат
(`как есть` / `жирный` / `с разметкой`). Шаблоны, сохранённые до появления
раздельных настроек (`format: markdown | plain | heading | bold | italic`),
читаются по-прежнему: значение автоматически раскладывается на обёртку и
разметку.

## Файлы и переводы

Во вкладках **«Папка»** (`data/input`) и **«Переводы»** (`data/output`) у каждого
файла есть три действия:

- **Переименовать** — расширение (`.json`) сохраняется автоматически,
  запрещённые символы заменяются на `_`, пробелы и кириллица разрешены;
  если имя занято, будет ошибка;
- **Удалить** — с подтверждением, файл физически удаляется из папки.

Ссылка работает, пока запущен сервер; при доступе из локальной сети замените
`localhost` на IP этого компьютера.

## Плейсхолдеры `{{поле}}`

В названии точки и в блоке «Текст» значение подставляется через `{{поле}}`
(поддерживаются вложенные пути — `{{sources.url}}`). Каждый плейсхолдер
показывается **чипом прямо в тексте**:

- **оранжевый** — такое поле есть в JSON;
- **красный** — поля нет в схеме (опечатка);
- при наведении — подсказка «Поле есть в JSON» / «Такого поля нет в JSON».

Чип — атомарный элемент: `Backspace` удаляет его целиком, курсор не заходит
внутрь. Пока плейсхолдер не закрыт (`{{categ`), он остаётся обычным текстом;
как только введены `}}` (или выбрана подсказка) — он превращается в чип.
Пробелы внутри скобок нормализуются: `{{ name }}` → `{{name}}`.

Автодополнение открывается, как только введены `{{`: `↑`/`↓` — выбор,
`Enter`/`Tab` — подставить, `Esc` — закрыть. Набранный или ошибочный
плейсхолдер заменяется целиком, курсор остаётся сразу после чипа.
Вставка из буфера всегда идёт как простой текст.

## Null-поля и условный разделитель

- Если поле в конкретной точке `null`/`undefined`/пустое — его блок описания
  **не выводится и не оставляет места** (ни пустой строки, ни лишнего `<br>`).
- Блок **«Разделитель»** можно сделать условным: в его настройках (иконка-карандаш)
  выберите поля — разделитель появится, только если хотя бы одно из них в точке
  не пустое. Без выбранных полей разделитель выводится всегда.
- В разделе **«Поля JSON»** видно, в скольких точках поле пусто (`null X/Y`),
  а если оно пустое во всех точках — показывается «всегда null».

## Перевод и сохранение прогресса

- Бесплатный эндпоинт Google Translate (`translate_a/t?client=dict-chrome-ex`).
- Строки группируются **по 50** и переводятся пачками; внутри пачки до 8
  параллельных запросов.
- Markdown/`<emo>`/URL перед переводом преобразуются в HTML, поэтому разметка
  сохраняется.
- Прогресс сохраняется после каждой пачки в `data/sessions/`; при повторном
  запуске с тем же файлом/полями/языком процесс продолжается с места остановки.
- **Отдельный предперевод**: кнопка «Перевести и сохранить JSON» переводит
  выбранные поля и пишет копию исходного JSON в `data/output`. Такие файлы
  видны во вкладке «Переводы» и загружаются обратно в интерфейс одним кликом —
  дальше можно конвертировать уже из готового переведённого JSON без повторного
  перевода.

## Ограничения

- Перевод требует доступа к `translate.googleapis.com`.
- Бесплатный эндпоинт перевода неофициальный и может ограничивать частоту;
  при ошибке строка остаётся в оригинале — можно повторить (прогресс сохранится).
- HTML-превью в браузере — приближение реального рендера Locus.
